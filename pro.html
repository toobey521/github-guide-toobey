1.5 注册与初始化设置

1
注册账号

访问 github.com → Sign up。用户名用小写英文+数字+连字符。推荐 Gmail 注册。

2
完善个人主页

Settings → Profile。设置头像（真人头像提高 PR 通过率30%）、Name、Bio（160字简介）、URL、Company/Location。

3
两步验证 2FA

Settings → Password and authentication → Two-factor authentication。推荐 Authenticator App（Google/Microsoft/Authy）。2023年起 GitHub 要求所有上传代码的用户启用 2FA！

4
SSH 密钥配置
ssh-keygen -t ed25519 -C "your@email.com"
eval "$(ssh-agent -s)" && ssh-add ~/.ssh/id_ed25519
cat ~/.ssh/id_ed25519.pub  # 复制添加到 GitHub
5
Git 本地配置
git config --global user.name "用户名"
git config --global user.email "邮箱"
git config --global init.defaultBranch main
git config --global pull.rebase true

2.4 Pull Request 深度拆解

三种 Merge 方式：Merge Commit（保留所有历史）/Squash and Merge（压缩成一个提交）/Rebase and Merge（线性历史）。

PR 标题规范：feat: 新功能、fix: Bug修复、docs: 文档、refactor: 重构、test: 测试、chore: 杂项。

最佳实践：一个 PR 只做一件事、小于 400 行改动、关联 Issue、运行测试通过后请求 Review。

2.5 Fork / Star / Watch

功能做了什么取消方式
Star ⭐收藏到个人 Stars 列表，点赞再次点击取消
Fork 🍴在自己账号下创建副本手动删除 Fork 仓库
Watch 👁订阅仓库动态通知改变级别/Unwatch

Watch 三种模式：Participating（只参与的被通知）、All Activity（全部通知）、Ignore（静音）。

05 协作开发

GitHub 的真正力量在于协作——多人异地同步开发。

5.1 Fork+PR 流程

1
Fork 上游仓库（点击 Fork 按钮）
2
Clone 到本地：git clone 你的Fork地址
3
添加上游：git remote add upstream 原仓库地址
4
创建功能分支：git checkout -b fix-bug
5
修改代码 → Commit → Push
6
在 GitHub 创建 PR → 等待 Review → 合并
7
合并后删除分支清理本地

5.3 保护分支

Settings → Branches → Add rule：Require PR before merging、Require approvals、Require status checks、Require signed commits、Conversation resolution。

5.4 分支策略

GitHub Flow — 简单，main+feature 分支，PR 即上线。Git Flow — 复杂，main+develop+feature+release+hotfix。Trunk-Based — 直接 main 小步提交。

06 GitHub Pages · 免费建站

不需要服务器、不需要域名、不需要备案——零成本上线网站。

两种站点：个人站点（仓库名=用户名.github.io，访问 https://用户名.github.io）和项目站点（Settings→Pages→选分支）。支持 Jekyll/Hugo/Hexo/VuePress/Docusaurus/纯静态 HTML。

自定义域名：DNS 添加 CNAME 记录指向 用户名.github.io，GitHub Settings 中设置域名，自动 HTTPS。

07 GitHub Actions · 自动化一切

CI/CD 不再是大型团队专利。

7.1 基础概念

Event 触发条件 → Workflow YAML 定义流程 → Job 单元任务 → Step 最小步骤 → Action 可复用模块 → Runner 虚拟机执行。

7.2 语法示例

name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v4
    - uses: actions/setup-python@v5
      with: { python-version: "3.11" }
    - run: pip install -r requirements.txt
    - run: pytest

7.4 常用 Actions

actions/checkout、actions/setup-*、actions/cache、actions/upload-artifact、peaceiris/actions-gh-pages、codecov/codecov-action、github/codeql-action。

17 常见错误

▶ Not a git repository
当前目录没有 .git。cd 到正确目录或 git init。
▶ Push rejected 非快进
需要先 git pull --rebase 拉取最新代码。
▶ Permission denied (publickey)
SSH Key 未配置或未添加到 GitHub。ssh -T git@github.com 测试。
▶ detached HEAD
checkout 了 commit 而非分支。git checkout -b 新分支 保存修改。
▶ 密码泄漏到公开仓库
立即改密码，用 git filter-branch 或 BFG Cleaner 清除历史，force push 覆盖。

19 FAQ 常见问题

▶ GitHub 免费吗？
个人使用完全免费：无限私有仓库、2000min Actions、500MB Packages。
▶ 不会代码用 GitHub 有用吗？
Markdown 写作、Pages 建站、Issue 任务管理、学习资源、翻译贡献。
▶ Fork 和 Clone 区别？
Fork 在云端复制到自己的账号。Clone 下载到本地。先 Fork 再 Clone。
▶ 如何删除仓库？
Settings → Danger Zone → Delete this repository。不可逆。
▶ Merge Conflict 怎么解决？
打开冲突文件，删除<<<=>>>标记，保留需要代码。git add → git commit。
▶ 怎么给开源项目贡献？
修文档、报告Bug、回答Issue、翻译、写测试、修 Good First Issue。
▶ 访问慢怎么办？
Steam++(Watt Toolkit)、FastGitHub、修改 Hosts、镜像站。
▶ 忘了 gitignore 上传了 node_modules？

▶ 怎么撤回 Commit？
未推送：git reset --soft HEAD~1。已推送：git revert HEAD。
▶ SemVer 语义化版本？
主版本.次版本.补丁。不兼容API→升主版本，新功能→升次版本，Bug修复→补丁。

22 Git 内部原理

.git 目录：objects/（对象存储）、refs/（引用）、HEAD（当前指针）、index（暂存区）。

三种核心对象：Blob（文件内容）、Tree（目录结构）、Commit（快照+父提交+作者+时间+信息）。

关键理解：Git 每个 Commit 存储全部文件的快照（不是差异），相同内容共享 Blob，所以高效。
